# Продукт: гайд «Видео-отдел в Claude Code за один вечер»

Гайд показывает, как собрать в Claude Code трёх ИИ-агентов, которые монтируют ролик вместо человека.

## Три агента
- Расшифровщик: прогоняет запись через whisper и находит паузы между фразами длиннее 0,6 секунды. Паузу внутри фразы не трогает.
- Оформитель: режет текст на субтитры по 3-5 слов и ставит плашки в точках, где меняется мысль.
- Сборщик: через ffmpeg вырезает помеченные паузы, накладывает субтитры и плашки, экспортирует в 1080 на 1920 со звуком на -14 LUFS.

## Что входит в гайд
- 3 файла-агента: готовая структура папки .claude/agents/, копируется как есть.
- Три готовых промпта под каждую роль.
- Команда запуска одной строкой: одно сообщение в Claude Code, агенты передают план друг другу по очереди.
- Чек-лист приёмки на 10 пунктов.
- 5 граблей и решения: плашка меняет размер, субтитр пишется капсом, ролик обрывается на полуслове.
- PDF приходит после оплаты.

## Для кого
Для тех, кто снимает видео для соцсетей, тратит вечера на монтаж или платит фрилансерам от 2000 до 8000 рублей за ролик.

## Что нужно для старта
- Доступ к Claude Code (терминальный агент, а не чат в браузере). Это отдельная подписка Anthropic, в цену гайда она не входит.
- Компьютер и запись видео, которое нужно смонтировать.
- Опыт с терминалом не нужен: недостающее (ffmpeg, whisper) Claude Code ставит по просьбе из гайда.
