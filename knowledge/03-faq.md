# Частые вопросы

Нужна ли подписка Claude? Да, нужен доступ к Claude Code. Это отдельная подписка Anthropic, в цену гайда она не входит.

У меня нет опыта с терминалом, справлюсь? Промпты копируются как есть, а ffmpeg и whisper Claude Code ставит по просьбе из гайда.

Это подписка или разовая оплата? Разовая оплата 1990 рублей. Повторных списаний нет.

Когда придёт файл? Сразу после оплаты. Если файл не пришёл, нужно написать Евгении, она поможет.

Если что-то не соберётся с первого раза? Это нормально, у автора тоже не с первого раза собралось. В гайде есть раздел «Пять граблей» с её затыками. Если не вышло, можно написать Евгении в личные сообщения или взять тариф с сопровождением.

Монтажёры теперь не нужны? Такого обещать нельзя. Гайд помогает за один вечер смонтировать один ролик своими силами, дальше решает сам человек.
